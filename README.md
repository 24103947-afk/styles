# Responsive Design — Bài thực hành của Huy

## Nội dung
- `index.html`: trang giới thiệu thế giới động vật
- `css/style.css`: CSS mobile-first và hai media query
- `images/`: 6 hình minh họa SVG đi kèm, chạy offline

## Yêu cầu đã triển khai
1. Mặc định trên điện thoại: mỗi thẻ chiếm 100% chiều rộng (một thẻ mỗi hàng).
2. Media Query 1 tại `min-width: 772px`: mỗi thẻ rộng khoảng 45%; ảnh có `max-height: 30vh`.
3. Media Query 2 tại `min-width: 998px`: mỗi thẻ rộng khoảng 30%.
4. Dùng Flexbox, `flex-wrap`, `justify-content`, khoảng cách giữa thẻ.
5. Ảnh có `alt`, bố cục tự thay đổi khi đổi kích thước cửa sổ.

## Kiểm tra
Mở `index.html` bằng trình duyệt. Thử độ rộng nhỏ hơn 772px, từ 772px đến 997px, và từ 998px trở lên.
Trước khi nộp, chạy kiểm tra HTML tại https://validator.w3.org/ và hoàn thành phần đánh giá ngang hàng của lớp.
